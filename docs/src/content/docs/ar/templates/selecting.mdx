## ما هو قابل للاختيار

**جميع القوالب الأساسية الخمسة عشر قابلة للاختيار.** السجل مغلق: أي معرّف ليس في هذه
القائمة يُرفض، ولا يُستبدل بصمت.

```
row  editorial  canvas  prism  terminal  pulse  brutal  arcade  sketch
signature  saffron  pulsenova  prismnova  terminalnova  arcadenova
```

**الافتراضي هو `row`.** أي تهيئة سابقة لوجود اختيار القوالب، أو تخزّن معرّفًا غير معروف،
تعود إلى `row` وتُعلن ذلك.

## أين يحدث الاختيار

**في التثبيت الجديد**، يعرض المثبّت التصاميم مباشرة ويطلب منك اختيار أحدها:

```
Choose your Row-Template design
  1  Row
  2  Editorial
  …
Select [1-15, Enter=Row]:
```

ضغط Enter يعني **Row**. ولا يُطبَّق شيء حتى تؤكّد الملخّص.

**بعد التثبيت**، بدّل التصميم من المدير:

```bash
row-template
```

ثم اختر **‏2 Reconfigure → ‏4 Template**. والتبديل معاملة كاملة من
اللقطة/التحقق/التفعيل، لذا يُعيد تبديلٌ فاشل التصميم السابق.

> **الأمر ‎`row-template config`‎ لا يختار قالبًا.** ذلك الأمر يغيّر الهوية فقط — اسم الخدمة
> ورابط الدعم والشعار.

## الاختيار دون طرفية

يُقرأ ‎`RT_TEMPLATE`‎ في **مسار التثبيت فقط**. وهو متغيّر بيئة، لذا يجب أن يكون السكربت
الذي يُطبَّق عليه متاحًا — أي عمليًا أن تشغّل ‎`install.sh`‎ من **حزمة إصدار مستخرجة**:

```bash
RT_TEMPLATE=prism bash install.sh
```

ويعمل أيضًا مع الأمر السطري البعيد، لأن البيئة تُورَّث:

```bash
RT_TEMPLATE=prism bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

**ولا أثر له على تثبيت قائم.** فالأمر ‎`row-template config`‎ لا يقرأه — استخدم المدير
للتبديل بعد التثبيت.

المعرّف غير الموجود في القائمة يُرفض، ويسمّي الخطأ المتاح:

```
RT_TEMPLATE='xyz' is not a template this release offers (available: row editorial …)
```

**القائمة مغلقة عن قصد.** فلا يمكن لخطأ مطبعي أن يثبّت تصميمًا آخر بصمت.

## ماذا يفعل الاختيار فعلًا

يحتفظ المثبّت **بملف موثّق واحد لكل تصميم** في مخزن القوالب داخل جذر التثبيت، لكلٍّ منها
checksum خاص. واختيار تصميم يُهيّئ ذلك الملف كصفحة مُقدَّمة، ثم يوائم الصفحة الحيّة معه.

ولأن كل ملف يُتحقَّق منه بchecksum الخاص، لا يمكن أن يبقى الاختيار نصف مُنفَّذ: إما أن
يكون التصميم المختار حيًّا، أو تُستعاد الحالة السابقة.

## ما تتوقّعه بعد ذلك

```bash
row-template verify
```

يذكر التحقق التصميم المختار ويؤكّد أن الصفحة المُقدَّمة تطابقه:

```
Template: Row
Canonical artifact matches the selected template.
```

والتهيئة التي تسمّي تصميمًا بينما تصميم آخر حيّ هي الحالة الوحيدة التي يجب ألّا يُبلّغ عنها
التحقق كسليمة — فيبلّغ عنها كفشل.

## كيف تختار بينها

الطريقة الصادقة للمقارنة بنيوية لا لونية.
[جدول المقارنة في المعرض](/ar/templates/#المقارنة-بالبنية) يسرد كل تصميم بعائلة التخطيط
والتركيب والكثافة والتجميع والعرض.

## ما لا يغيّره التبديل

- **هويتك** — اسم الخدمة ورابط الدعم والشعار تبقى.
- **بيانات مشتركيك.**
- **وقت التشغيل واللغات وسلوك رمز QR.**
