ثلاث خطوات. كل خطوة تخبرك بما ينبغي أن تراه، وما تفعله إن لم تره.

## قبل أن تبدأ

- **‎3X-UI‎ الإصدار ‎3.6.0‎ أو أحدث.** تحقّق عبر ‎`x-ui`‎ أو من اللوحة نفسها.
- **صلاحيات root.** التثبيت يغيّر النظام.
- **وصول إلى GitHub.** ينزّل سكربت الإقلاع الإصدار عبر HTTPS. للتركيب دون اتصال انظر
  [التثبيت دون اتصال](#التثبيت-دون-اتصال).

## الخطوة ١ — التثبيت

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

يجلب السكربت أرشيف الإصدار، **ويتحقق من checksum**، ويفكّه بأمان، ثم يسلّم عملية التثبيت
كاملة إلى مكتبة الإدارة.

**المتوقع:** يذكر المثبّت الإصدار الذي يثبّته، ثم يسأل عن اسم الخدمة ورابط الدعم والشعار.
اضغط Enter لتخطي أي سؤال — الثلاثة اختيارية.

**إذا فشل:**

| الرسالة | المعنى | ما تفعله |
|---|---|---|
| ‎`3x-ui <version> is below the required minimum 3.6.0; not installing`‎ | لوحتك أقدم من الحد الأدنى المدعوم. | حدّث ‎3X-UI‎ أولًا ثم أعد التشغيل. |
| ‎`an existing install was found at …`‎ | رو-تمبلت مثبّت مسبقًا. | شغّل ‎`row-template update`‎، أو أعد التشغيل مع ‎`RT_ASSUME_YES=1`‎ للإصلاح. |
| رفض بسبب checksum | التنزيل ناقص أو الملف ليس من الإصدار الرسمي. | أعد التنزيل من صفحة الإصدارات الرسمية. **لا تتجاوز هذا الفحص.** |
| خطأ في الشبكة | تعذّر الوصول إلى GitHub. | أعد المحاولة أو استخدم [التثبيت دون اتصال](#التثبيت-دون-اتصال). |

## الخطوة ٢ — التفعيل

يحاول المثبّت ذلك نيابةً عنك، وينجح عند توفّر ‎`sqlite3`‎ على الخادم.

**إن لم يُفعَّل تلقائيًا**، اضبطه مرة واحدة في اللوحة:

> **Panel Settings → Subscription → Profile → Sub Theme Directory**

وأدخل بالضبط:

```
/etc/3x-ui/sub_templates/row-template
```

**المتوقع:** عند فتح رابط الاشتراك تظهر صفحة رو-تمبلت بدلًا من صفحة اللوحة المدمجة.

## الخطوة ٣ — التحقق

```bash
row-template verify
```

هذا الأمر للقراءة فقط. يفحص الملف المثبَّت وربط اللوحة والعرض الحيّ.

**المتوقع:** كل الفحوص بحالة OK. وإن فشل فحص، يذكر ما فشل وبأي قيمة وجدها.

## التثبيت دون اتصال

إذا تعذّر على الخادم الوصول إلى GitHub، نزّل ملفات الإصدار على جهاز آخر من
[صفحة الإصدارات](https://github.com/frank0live/Row-Template/releases/latest)،
وتحقّق من checksum بنفسك، وانقلها، ثم شغّل ‎`install.sh`‎ المرفق من المجلد المفكوك.

## بعد التثبيت

```bash
row-template
```

التشغيل دون وسائط في طرفية يفتح المدير التفاعلي — الأوامر نفسها في قائمة.
