**نظام متعدد القوالب لصفحة الاشتراك في ‎3X-UI‎.** تُشحن خمسة عشر تصميمًا مع المشروع. أيًّا
اخترت، تكون النتيجة ملف HTML واحدًا مستقلًا تملكه أنت، ويرى مشتروك خدمتك — لا خدمتنا.

[التثبيت](/ar/installation/) · [تصفّح القوالب](/ar/templates/)

## ما هو

يستبدل رو-تمبلت صفحة الاشتراك المدمجة في اللوحة بأحد خمسة عشر تصميمًا. ليس لوحة، ولا قالبًا
لواجهة الإدارة، ولا تطبيق عميل — يغيّر فقط ما يراه مشتروك.

وهو **بلا علامة تجارية افتراضيًا**. اسم خدمتك ورابط دعمك وشعارك ملكك، وتبقى عبر التحديثات،
ولا يظهر اسم رو-تمبلت نفسه في الصفحة المُقدَّمة إلا إذا أدخلته بنفسك.

## الحقائق

| | |
|---|---|
| **اللوحة** | ‎3X-UI‎ الإصدار **‎3.6.0‎** أو أحدث — اللوحة الوحيدة المدعومة في الإنتاج |
| **القوالب** | **١٥**، كلها متاحة ومقفلة بـ checksum |
| **المخرجات** | ملف واحد مستقل، داخل سقف ‎204,800‎ بايت |
| **بيئة التشغيل** | لا شيء — بلا Node.js‎ وبلا Python وبلا قاعدة بيانات على الخادم |
| **الطلبات** | الصفحة المُقدَّمة لا تطلب شيئًا من أي مصدر |
| **اللغات** | English · فارسی · العربية · Русский · 简体中文 |
| **الاتجاه** | العربية والفارسية نمطا تخطيط، لا انعكاسًا لاحقًا |
| **المستندات** | الإنجليزية والفارسية والعربية |

## القوالب

خمسة عشر تصميمًا تختلف في **البنية** لا في اللون — عمود واحد، عمود قراءة ضيّق، سجلة
متعددة الأوجه، لوحة معلومات، لوحة عريضة، طرفية. وتشترك جميعها في وقت التشغيل والبيانات
والضمانات نفسها.

[اطّلع على الخمسة عشر، مقارَنة بالبنية ←](/ar/templates/)

## التثبيت في سطر واحد

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

ثم أدِر التثبيت بالأمر ‎`row-template`‎:

```bash
row-template verify
```

## عن هذه المستندات

تتوفر هذه المستندات بـ**الإنجليزية والفارسية والعربية**. الإنجليزية هي المصدر المعتمد،
والعربية والفارسية أوليّة بتخطيط من اليمين إلى اليسار، لا انعكاس لاحق.

وكل ما يُقتبس من المثبّت أو سطر الأوامر يبقى بـ**الإنجليزية** في كل اللغات، لأنه المخرَج
الفعلي للأدوات.
