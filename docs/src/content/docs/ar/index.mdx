رو-تمبلت يستبدل صفحة الاشتراك الافتراضية في اللوحة بصفحة تتحكم بها أنت. تُثبَّت
**كملف HTML واحد مستقل بذاته** وتُقدَّم عبر ‎3X-UI‎، فيحصل مشتروك على صفحة سريعة ومقروءة
ومملوكة لك بالكامل.

الصفحة بلا علامة تجارية افتراضيًا. يرى مشتروك **اسم خدمتك** ورابط دعمك وشعارك — لا شعارنا.

## ما يحصل عليه مشتروك

صفحة قابلة للاستخدام فعلًا: حالة الاشتراك، والاستهلاك المتبقي، وتاريخ الانتهاء، وقائمة
الإعدادات مع الاستيراد بضغطة واحدة، وإرشادات الإعداد لكل تطبيق، ورمز QR. تعمل دون اتصال،
ولا تعتمد على أي خدمة خارجية، وتُفتح فورًا.

## ما تحصل عليه أنت

أمر واحد للتثبيت، وأمر واحد لإعادة التهيئة، وملف مستقل يمكنك التحقق منه عبر checksum.
بلا Node.js‎ وبلا Python وبلا قاعدة بيانات — بيئة لينكس القياسية فقط.

## من أين تبدأ

**التثبيت.** أمر واحد ثم بعض الأسئلة القصيرة عن الهوية. [دليل التثبيت](/ar/installation/)

**اختيار المظهر.** خمسة عشر تصميمًا تُشحن مع المشروع. [معرض القوالب](/ar/templates/)

**ضبط هويتك.** اسم الخدمة ورابط الدعم والشعار — كلها اختيارية. [الهوية](/ar/branding/)

**حدثت مشكلة.** [استكشاف الأخطاء](/ar/troubleshooting/)

## التثبيت في سطر واحد

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

ثم أدِر التثبيت بالأمر ‎`row-template`‎:

```bash
row-template verify
```

## المتطلبات

| | |
|---|---|
| اللوحة | **‎3X-UI‎ الإصدار ‎3.6.0‎ أو أحدث** |
| الخادم | أي لينكس يحتوي على ‎`bash`‎ و‎`coreutils`‎ و‎`curl`‎ و‎`tar`‎ و‎`sha256sum`‎ |
| بيئة التشغيل | لا شيء — بلا Node.js‎ وبلا Python وبلا قاعدة بيانات |
| الصلاحيات | root، للأوامر التي تغيّر النظام |
