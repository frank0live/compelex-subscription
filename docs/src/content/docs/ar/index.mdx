رو-تمبلت يحوّل رابط الاشتراك إلى صفحة يمكن للمشترك استخدامها فعلاً: الحالة، والاستهلاك،
وتاريخ الانتهاء، وقائمة الإعدادات، والاستيراد بضغطة واحدة إلى التطبيق. تُثبَّت
**كملف HTML واحد مستقل** ولا ترسل أي طلب إلى طرف ثالث.

## لماذا تختلف هذه الصفحة

كل شيء داخل الملف نفسه. الأنماط والجافاسكربت والخطوط ومولِّد رمز QR كلها مضمَّنة في الملف
ذاته، لذلك لا تعتمد الصفحة التي يفتحها المشترك على أي مصدر خارجي. وهذا يعني أنها تعمل
دون اتصال، ويمكن التحقق منها عبر checksum.

### التثبيت على الخادم

يتم التثبيت عبر سكربت واحد يعمل على بيئة لينكس القياسية. لا يحتاج إلى Node.js أو Python
أو قاعدة بيانات. للتحقق من النسخة المثبَّتة استخدم `row-template verify`.

```sh
curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh | sh
```

## الجدول

| القالب | البنية | الحجم (بايت) |
|---|---|---|
| row | نظام معلوماتي مرجعي وبسيط | 200999 |
| terminal | ورقة جلسة نصية | 199642 |

## الخطوات

1. نزّل سكربت التثبيت وقارن checksum بالقيمة المنشورة.
2. شغّل السكربت واختر اللوحة.
3. **التحقق:** يجب أن يُظهر الناتج اسم القالب وكلمة `installed`.

:::caution
خُذ نسخة احتياطية قبل التحديث. إذا توقف السكربت برسالة `refusing` فتعامل معها بجدية
وأصلح السبب بدلاً من تجاوز الفحص.
:::
