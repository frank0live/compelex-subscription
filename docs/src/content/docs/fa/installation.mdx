سه مرحله. هر مرحله می‌گوید چه چیزی باید ببینید و اگر ندیدید چه کنید.

## پیش از شروع

- **۳X-UI نسخهٔ ۳.۶.۰ یا بالاتر.** با `x-ui` یا از خود پنل بررسی کنید. نصب‌کننده پایین‌تر
  از این را نمی‌پذیرد و نسخهٔ تشخیص‌داده‌شده را گزارش می‌کند.
- **دسترسی root.** نصب سیستم را تغییر می‌دهد.
- **دسترسی به GitHub.** اسکریپت راه‌انداز نسخه را روی HTTPS دانلود می‌کند. برای نصب آفلاین
  بخش [نصب آفلاین](#نصب-آفلاین) را ببینید.

## مرحلهٔ ۱ — نصب

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

اسکریپت، آرشیو نسخه را می‌گیرد، **checksum آن را بررسی می‌کند**، به‌شکل ایمن بازش می‌کند و
کل عملیات نصب را به کتابخانهٔ مدیریت می‌سپارد.

**انتظار:** نصب‌کننده نسخه‌ای که نصب می‌کند را گزارش می‌دهد و سپس نام سرویس، لینک پشتیبانی و
لوگو را می‌پرسد. با زدن Enter از هر پرسشی بگذرید — هر سه اختیاری‌اند.

**اگر شکست خورد:**

| پیام | معنی | کار |
|---|---|---|
| `3x-ui <version> is below the required minimum 3.6.0; not installing` | پنل شما قدیمی‌تر از حداقل نسخهٔ پشتیبانی‌شده است. | ابتدا ۳X-UI را به‌روز کنید، سپس دوباره اجرا کنید. |
| `an existing install was found at …` | رو-تمپلیت از قبل نصب است. | `row-template update` را اجرا کنید، یا با `RT_ASSUME_YES=1` نصب موجود را ترمیم کنید. |
| امتناع به‌دلیل checksum | دانلود ناقص بوده یا فایل از منبع رسمی نیامده است. | از صفحهٔ رسمی انتشار دوباره دانلود کنید. **این بررسی را دور نزنید.** |
| خطای شبکه | GitHub در دسترس نبوده. | دوباره تلاش کنید، یا از [نصب آفلاین](#نصب-آفلاین) استفاده کنید. |

## مرحلهٔ ۲ — فعال‌سازی

نصب‌کننده تلاش می‌کند این کار را خودش انجام دهد و در صورت وجود `sqlite3` موفق می‌شود.

**اگر خودکار فعال نشد**، یک‌بار در پنل تنظیمش کنید:

> **Panel Settings → Subscription → Profile → Sub Theme Directory**

دقیقاً این را وارد کنید:

```
/etc/3x-ui/sub_templates/row-template
```

**انتظار:** با باز کردن لینک اشتراک، به‌جای صفحهٔ داخلی پنل، صفحهٔ رو-تمپلیت نمایش داده شود.

## مرحلهٔ ۳ — بررسی

```bash
row-template verify
```

فایل نصب‌شده، اتصال پنل و رندر زنده را بررسی می‌کند. اگر با دسترسی root اجرا شود، ابتدا
مخزن طرح‌ها را درست می‌کند: طرح‌هایی که بیرون از `dist/templates` مانده‌اند به جای خود
برمی‌گردند، و طرح‌هایی که نسخهٔ نصب‌شده دارد ولی روی سرور نیستند از همان نسخه دریافت
می‌شوند. جز این چیزی را تغییر نمی‌دهد.

**انتظار:** همهٔ بررسی‌ها OK باشند. اگر بررسی‌ای شکست بخورد، می‌گوید چه چیزی و با چه مقداری
شکست خورده، و پیام‌های خود نصب‌کننده می‌گویند بعد چه دستوری را اجرا کنید.

## نصب آفلاین

اگر سرور به GitHub دسترسی ندارد، فایل‌های انتشار را روی ماشین دیگری از
[صفحهٔ انتشار](https://github.com/frank0live/Row-Template/releases/latest) دانلود کنید،
خودتان checksum را بررسی کنید، منتقلشان کنید و `install.sh` همراه آرشیو را از پوشهٔ بازشده
اجرا کنید.

## پس از نصب

```bash
row-template
```

اجرای بدون آرگومان در ترمینال، مدیر تعاملی را باز می‌کند؛ همان دستورها، در قالب یک منو.
