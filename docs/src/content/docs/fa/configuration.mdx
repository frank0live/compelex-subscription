همه‌چیز با یک دستور مدیریت می‌شود. اجرای بدون آرگومان در ترمینال، مدیر تعاملی را باز می‌کند؛
یا مستقیماً زیرفرمان را صدا بزنید.

```bash
row-template
```

## دستورها

| دستور | کار | سیستم را تغییر می‌دهد؟ |
|---|---|---|
| `row-template config` | تغییر نام سرویس، آدرس پشتیبانی یا لوگو و ساخت دوبارهٔ صفحه | بله — root |
| `row-template update` | دانلود، بررسی و فعال‌سازی نسخهٔ جدیدتر (با الزام checksum) | بله — root |
| `row-template rollback` | بازگردانی نسخهٔ پیشین (`--auto` یا `--to <backup-dir>`) | بله — root |
| `row-template verify` | بررسی نصب، اتصال پنل و رندر زنده | **نه** — فقط خواندنی |
| `row-template version` | نمایش نسخهٔ نصب‌شده، حداقل نسخهٔ پشتیبانی‌شده و نسخهٔ ۳X-UI شناسایی‌شده | **نه** — فقط خواندنی |
| `row-template uninstall` | حذف رو-تمپلیت و بازگرداندن پنل به صفحهٔ داخلی | بله — root |
| `row-template menu` | باز کردن صریح مدیر تعاملی | — |
| `row-template help` | نمایش راهنما | — |

دستورهایی که سیستم را تغییر می‌دهند باید با root اجرا شوند.

## اجرا بدون ترمینال

اجرای بدون آرگومان در ترمینال، مدیر را باز می‌کند. در محیط غیرتعاملی — اسکریپت، CI یا
`curl | bash` — به‌جای منتظر ماندن، راهنما چاپ می‌شود تا هیچ‌وقت برنامه معلق نماند. متغیر
`RT_ASSUME_NONINTERACTIVE` این رفتار را صریحاً تحمیل می‌کند.

## خواندن وضعیت فعلی

```bash
row-template version
```

نسخهٔ نصب‌شده، حداقل نسخهٔ پشتیبانی‌شدهٔ ۳X-UI و نسخهٔ شناسایی‌شدهٔ ۳X-UI روی سرور را چاپ
می‌کند. پیش از گزارش هر مشکلی، این را اجرا کنید.

```bash
row-template verify
```

فایل نصب‌شده، اتصال پنل و رندر زنده را بررسی می‌کند. فقط خواندنی است، پس همیشه بی‌خطر است.

## به‌روزرسانی

```bash
row-template update
```

کانال انتشار پایدار عمومی را بررسی می‌کند، نسخهٔ نصب‌شده و موجود را نشان می‌دهد، و **فقط
وقتی نسخهٔ پایدار جدیدتری وجود دارد** به‌روزرسانی می‌کند. اگر شبکه یا منبع انتشار در دسترس
نباشد، می‌گوید که نتوانست بررسی کند — نصب شما هرگز آسیب‌دیده فرض نمی‌شود.

**تنظیمات برند شما در به‌روزرسانی حفظ می‌شود.**

## بازگردانی

```bash
row-template rollback
```

نسخهٔ پیشین را از یک پشتیبان معتبر بازمی‌گرداند. ابتدا از نسخهٔ فعلی هم پشتیبان گرفته می‌شود،
بنابراین یک بازگردانی ناموفق هم قابل بازیابی است.

```bash
row-template rollback --to <backup-dir>
```

بازگردانی به یک پشتیبان مشخص، به‌جای نسخهٔ قبلی.

## حذف نصب

```bash
row-template uninstall
```

رو-تمپلیت و فایل‌هایش را حذف می‌کند و پنل را به صفحهٔ داخلی خودش برمی‌گرداند. به ۳X-UI،
پایگاه‌داده، اینباندها، کلاینت‌ها یا گواهی‌های شما **دست نمی‌زند**.

حذف غیرتعاملی به `RT_ASSUME_YES=1` نیاز دارد.
