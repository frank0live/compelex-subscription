رو-تمپلیت صفحهٔ پیش‌فرض اشتراک پنل را با صفحه‌ای جایگزین می‌کند که کاملاً در اختیار شماست.
این صفحه به‌صورت **یک فایل HTML مستقل** نصب می‌شود و از طریق ۳X-UI ارائه می‌شود؛ بنابراین
مشترک شما صفحه‌ای سریع، خوانا و کاملاً متعلق به شما می‌بیند.

به‌طور پیش‌فرض کاملاً بی‌نام‌ونشان است. مشترک شما **نام سرویس شما**، لینک پشتیبانی شما و
لوگوی شما را می‌بیند — نه مال ما را.

## مشترک شما چه چیزی می‌بیند

صفحه‌ای که واقعاً به کار می‌آید: وضعیت اشتراک، مصرف و باقی‌ماندهٔ حجم، تاریخ انقضا، فهرست
کانفیگ‌ها با ورود یک‌کلیکی، راهنمای راه‌اندازی برای هر کلاینت، و کد QR. بدون اینترنت هم کار
می‌کند، به هیچ سرویس شخص ثالثی وابسته نیست، و بی‌درنگ باز می‌شود.

## شما چه چیزی به دست می‌آورید

یک دستور برای نصب، یک دستور برای تغییر تنظیمات، و یک فایل مستقل که می‌توانید با checksum
تأییدش کنید. نه Node.js، نه پایتون، نه پایگاه‌داده — فقط کاربری استاندارد لینوکس.

## از کجا شروع کنید

**نصب.** یک دستور، و بعد چند پرسش کوتاه دربارهٔ برند. [راهنمای نصب](/fa/installation/)

**انتخاب ظاهر.** پانزده طرح همراه پروژه عرضه می‌شود.
[گالری تمپلیت](/fa/templates/)

**تنظیم برند خودتان.** نام سرویس، لینک پشتیبانی و لوگو — همه اختیاری.
[برندسازی](/fa/branding/)

**مشکلی پیش آمده.** [رفع اشکال](/fa/troubleshooting/)

## خلاصهٔ نصب

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

سپس مدیریت نصب با دستور `row-template`:

```bash
row-template verify
```
