**یک سامانهٔ چند-تمپلیتی صفحهٔ اشتراک برای ۳X-UI.** پانزده طرح همراه پروژه عرضه می‌شود.
هر کدام را انتخاب کنید، نتیجه یک فایل HTML مستقل است که در اختیار شماست، و مشترک شما سرویس
شما را می‌بیند — نه ما را.

[نصب](/fa/installation/) · [دیدن تمپلیت‌ها](/fa/templates/)

## چیست

رو-تمپلیت صفحهٔ اشتراک داخلی پنل را با یکی از پانزده طرح جایگزین می‌کند. نه پنل است، نه
پوسته‌ای برای بخش مدیریت، و نه کلاینت — فقط چیزی را تغییر می‌دهد که مشترک شما می‌بیند.

به‌طور پیش‌فرض **کاملاً بی‌نام‌ونشان** است. نام سرویس، لینک پشتیبانی و لوگوی شما متعلق به
خودتان است، در به‌روزرسانی‌ها باقی می‌ماند، و نام خود رو-تمپلیت هیچ‌جای صفحهٔ ارائه‌شده دیده
نمی‌شود مگر خودتان آن را وارد کنید.

## واقعیت‌ها

| | |
|---|---|
| **پنل** | ۳X-UI نسخهٔ **۳.۶.۰** یا بالاتر — تنها پنل پشتیبانی‌شدهٔ عملیاتی |
| **تمپلیت‌ها** | **۱۵**، همه در دسترس، همه قفل‌شده با checksum |
| **خروجی** | یک فایل مستقل، در سقف ۲۰۴٬۸۰۰ بایت |

| **درخواست‌ها** | صفحهٔ ارائه‌شده به هیچ منبعی درخواست نمی‌فرستد |
| **زبان‌ها** | English · فارسی · العربية · Русский · 简体中文 |
| **راست‌به‌چپ** | فارسی و عربی حالت چیدمان‌اند، نه بازتاب‌دادن پس از ساخت |
| **مستندات** | انگلیسی، فارسی و عربی |

## تمپلیت‌ها

پانزده طرح که در **ساختار** تفاوت دارند نه در رنگ — تک‌ستونی، ستون باریک خوانا، رکورد
چندوجهی، داشبورد، تختهٔ پهن، کنسول. همه در زمان اجرا، داده و تضمین‌ها مشترک‌اند.

## خلاصهٔ نصب

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

سپس مدیریت نصب با دستور `row-template`:

```bash
row-template verify
```

## دربارهٔ این مستندات

این مستندات به **انگلیسی، فارسی و عربی** در دسترس است. انگلیسی مرجع اصلی است؛ فارسی و
عربی درجه‌یک‌اند و چیدمان راست‌به‌چپ دارند، نه بازتابی پس از ساخت.

هر چیزی که از نصب‌کننده یا خط فرمان نقل شود، در همهٔ زبان‌ها **انگلیسی** می‌ماند، چون
خروجی واقعی ابزار همان است.
