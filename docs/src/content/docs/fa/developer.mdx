این صفحه برای کسانی است که روی خود رو-تمپلیت کار می‌کنند یا تمپلیتی بر پایهٔ آن می‌سازند.

## چیدمان مخزن

```
src/
  styles/                  شیوه‌نامهٔ Row — Row همیشه اینجا بوده
  templates/<id>/          چیدمان و CSS هر تمپلیت دیگر
    layout.html
    tokens.css  base.css  layout.css  components.css  rtl.css
  scripts/                 زمان اجرای مشترک — هرگز مخصوص یک تمپلیت
  locales/                 جزیرهٔ زبان‌های مشترک
tools/
  templates.mjs            فهرست تمپلیت‌ها
  build.mjs                build()، validateLayout()، REQUIRED_HOOKS
  verify.mjs
tests/                     مجموعه آزمون محصول
installer/                 نصب‌کنندهٔ راه‌انداز و کتابخانهٔ مدیریت
docs/                      همین سایت مستندات (فضای کاری جدا)
```

## ساخت

```bash
npm run build     # ساخت دوبارهٔ فایل‌های خروجی از src/
npm run verify    # بررسی فایل خروجی در برابر دروازه‌های ایمنی
npm test          # مجموعهٔ کامل آزمون‌های محصول
```

ساخت **قطعی** است — منابع یکسان همیشه خروجی بایت‌به‌بایت یکسان می‌سازند. همین است که قفل‌های
بایتی را معنادار می‌کند.

## قرارداد فایل خروجی

یک فایل ساخته‌شده باید همهٔ این‌ها را برآورده کند:

| الزام | بررسی‌کننده |
|---|---|
| **۷۹ قلاب**، هرکدام دقیقاً یک‌بار | `validateLayout()` و آزمون‌های ساخت |
| **دقیقاً سه تگ `<script>`** | آزمون‌های ساخت |
| هم‌ارزی بایتی اسکریپت راه‌انداز و برنامه با Row | آزمون‌های ساخت |
| هم‌ارزی بایتی جزیرهٔ زبان‌ها | آزمون‌های ساخت |
| یک بلوک `<style>` بدون توکن جانشین‌نشده | آزمون‌های ساخت |
| در سقف **۲۰۴٬۸۰۰ بایت** | آزمون‌های ساخت |
| وجود نشانگر `/* row:branding */` | آزمون‌های ساخت |

## انتخاب چیدمان

`loadLayout()` در `tools/build.mjs` اگر فایل `src/templates/<id>/layout.html` وجود داشته
باشد همان را می‌خواند و در غیر این صورت به `src/index.html` برمی‌گردد.

**هر پانزده تمپلیت اصلی `layout.html` خودشان را دارند، پس این بازگشت هرگز اتفاق نمی‌افتد و
`src/index.html` کد مرده است.** مدل پوستهٔ مشترک بازنشسته شده است.

## فهرست تمپلیت‌ها

`tools/templates.mjs` فهرست بسته و معتبر است. هر ورودی این‌ها را دارد:

| فیلد | معنی |
|---|---|
| `id`، `name` | شناسهٔ پایدار و نام نمایشی |
| `order` | ترتیب — تنها سازوکار مرتب‌سازی |
| `available` | آیا در این نسخه قابل انتخاب است |
| `emitDataTemplate` | آیا فایل خروجی `data-template` روی `<html>` دارد |
| `styles` | فایل‌های CSS مرتب، به‌صورت جفت `[منبع، برچسب]` |
| `tier`، `locked` | به‌طور پیش‌فرض اعمال می‌شوند: `core` و `true` |

شناسهٔ ناشناخته یا غیرفعال، با صدای بلند شکست می‌خورد و بی‌صدا به Row برنمی‌گردد.

## دروازه‌های بررسی

- **قفل بایتی** — هر تمپلیت اصلی به اندازهٔ دقیق و SHA-256 قفل شده است.
- **قطعیت** — دو بار ساخت، بایت‌های یکسان تولید می‌کند.
- **اعتبارسنجی ساختاری** — قرارداد قلاب‌ها و اسکریپت‌ها، هنگام ساخت اعمال می‌شود.
- **مقایسهٔ پانزده‌گانهٔ بایتی** — بررسی اینکه تغییری هیچ فایل قفل‌شده‌ای را جابه‌جا نکرده است.
