## انتخاب

تمپلیت درست به این بستگی دارد که سرویس شما چیست. چند نقطهٔ شروع صادقانه:

| اگر می‌خواهید… | با این شروع کنید |
|---|---|
| ساکت‌ترین صفحهٔ ممکن | **Row** — طرح مرجع و مینیمال |
| چیزی که مثل یک نشریه خوانده شود | **Editorial** یا **Saffron** |
| حس داشبورد | **Pulse** یا **Pulse Nova** |
| اطلاعات متراکم و ساخت‌یافته | **Prism** یا **Prism Nova** |
| لحن فنی و نزدیک به ترمینال | **Terminal** یا **Terminal Nova** |
| گزینه‌های اصلی قوی و جسور | **Brutal**، **Arcade** یا **Arcade Nova** |
| ارائه‌ای ممتاز و سندگونه | **Signature** |

این‌ها برای جهت‌یابی است، نه رتبه‌بندی. هر تمپلیت یک طرح کامل و پشتیبانی‌شده است.

## آزمون بهتر

چون تمپلیت‌ها **ساختاری** از هم متفاوت‌اند و نه با رنگ، آزمون صادقانه این است که آن‌ها را
سیاه‌وسفید ببینید. تمپلیتی که بدون پالتش هم خودش را نشان می‌دهد، هویت واقعی دارد.

## جابه‌جایی

انتخاب تمپلیت بخشی از نصب است، پس جابه‌جایی یک پیکربندی دوباره است. مدیر را اجرا کنید و
از همان‌جا تغییرش دهید:

```bash
row-template config
```

## انتخاب از خط فرمان

برای نصب‌های اسکریپتی یا بدون‌ناظر، تمپلیت را می‌توان با متغیر محیطی `RT_TEMPLATE` انتخاب کرد:

```bash
RT_TEMPLATE=prism bash install.sh
```

مقدار ناشناخته رد می‌شود و خطا فهرست تمپلیت‌های همین نسخه را نشان می‌دهد — فهرست بسته است،
پس یک غلط تایپی هرگز نمی‌تواند بی‌صدا طرح دیگری نصب کند.

## جابه‌جایی چه چیزی را تغییر نمی‌دهد

- برند شما — نام سرویس، لینک پشتیبانی و لوگو باقی می‌مانند.
- داده‌های مشترکین شما.
- زمان اجرا، زبان‌ها و رفتار کد QR.
