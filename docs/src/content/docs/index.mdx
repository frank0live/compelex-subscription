**A multi-template subscription page system for 3X-UI.** Seventeen designs ship with the
project. Whichever you choose, the result is one self-contained HTML file that you
control, and your subscribers see your service — not ours.

[Install it](/installation/) · [Browse the templates](/templates/)

## What it is

Row-Template replaces the panel's built-in subscription page with one of seventeen designs.
It is not a panel, not a theme for the admin interface, and not a client — it changes only
what your subscribers see.

It is **white-label by default**. Your service name, support link and logo are yours, they
persist across updates, and Row-Template's own name appears nowhere on the served page
unless you enter it yourself.

## Facts

| | |
|---|---|
| **Panel** | 3X-UI **3.6.0** or newer — the only supported production panel |
| **Templates** | **17**, all available, all byte-locked |
| **Output** | One self-contained artifact, within a 204,800-byte ceiling |
| **Runtime** | None — no Node.js, no Python, no database on the server |
| **Requests** | The served page fetches nothing from anywhere |
| **Locales** | English · فارسی · العربية · Русский · 简体中文 |
| **RTL** | Persian and Arabic are layout modes, not mirroring passes |
| **Docs** | English, Persian and Arabic |

## The templates

Seventeen designs, differing in **structure** rather than in colour — a single column, a
narrow reading column, a faceted record, a dashboard, a wide board, a console. They share
the same runtime, the same data and the same guarantees.

## The short version

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

Then manage the installation with `row-template`:

```bash
row-template verify
```

## This documentation

These docs are available in **English, Persian and Arabic**. English is the source of
truth; Persian and Arabic are first-class, with right-to-left layout rather than a
mirrored afterthought.

Anything quoted from the installer or the command line stays in **English** in every
locale, because that is what the tools actually print.
