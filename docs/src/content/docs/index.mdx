Row-Template replaces the panel's default subscription page with one you control. It
installs as **a single self-contained HTML file** and serves it through 3X-UI, so your
subscribers get a page that is fast, readable, and entirely yours.

It is white-label by default. Your subscribers see **your** service name, your support
link and your logo — not ours.

## What it gives your subscribers

A page they can actually use: subscription status, traffic used and remaining, expiry
date, a list of configurations with one-tap import, per-client setup instructions, and
a QR code. It works offline, needs no third-party service, and loads instantly.

## What it gives you

One command to install, one command to reconfigure, and a self-contained artifact that
you can verify by checksum. No Node.js, no Python, no database on the server — standard
Linux userland only.

## Where to start

**Installing it.** One command, then a short branding prompt. See

**Choosing a look.** Fifteen designs ship with the project. See the

**Setting your brand.** Service name, support link and logo — all optional. See

**Something is wrong.** See [Troubleshooting](/troubleshooting/).

## The short version

```bash
bash <(curl -fsSL https://github.com/frank0live/Row-Template/releases/latest/download/install.sh)
```

Then manage the installation with `row-template`:

```bash
row-template verify
```

## Requirements

| | |
|---|---|
| Panel | **3X-UI 3.6.0 or newer** |
| Server | Any Linux with `bash`, `coreutils`, `curl`, `tar`, `sha256sum` |
| Runtime | None — no Node.js, no Python, no database |
| Access | Root, for the commands that change the system |

## Languages

The subscription page ships in five interface languages and follows the subscriber's
panel or browser locale:

**English · فارسی · العربية · Русский · 简体中文**

Persian and Arabic render right-to-left.
